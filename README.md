# English–Turkish Dictionary for Kindle

The biggest English to Turkish dictionary for Kindle.

- **948,931** English headwords
- **2,241,858** Turkish translations
- **56,215** extra word forms (plurals, verb tenses and so on), so looking up an inflected word finds its entry

It works as a real Kindle lookup dictionary: press and hold a word in any English book and the Turkish translations appear in the popup. Tested and working on Kindle Paperwhite 12th generation, firmware 5.19.4.

## Download

**[English-Turkish-Dictionary.mobi](https://github.com/jayaliyev/kindle-english-turkish-dictionary/releases/latest/download/English-Turkish-Dictionary.mobi)** (118 MB)

## Install

1. Connect the Kindle to your computer with a USB data cable.
2. Copy `English-Turkish-Dictionary.mobi` into the Kindle's `documents` folder.
3. Disconnect and give the Kindle a few minutes to index the file.
4. Open **All Settings → Language & Dictionaries → Dictionaries → English** and choose **English–Turkish Dictionary**.
5. Open an English book and press and hold a word.

Copy the file over USB as it is. Converting it, or sending it through Send to Kindle, can remove the lookup index.

## Notes

- Built with Amazon KindleGen.
- The numbers next to translations label alternatives, not separate senses. There is no pronunciation or etymology data.
